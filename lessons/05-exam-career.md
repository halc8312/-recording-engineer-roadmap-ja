# 05 資格、著作権、作品集、仕事へのつなげ方

## 1. 資格の位置づけ

録音エンジニアは免許がないと働けない職業ではありません。厚生労働省job tagも、入職に特定の学歴・資格は必要とされず、JAPRS資格は技術の証明になると説明しています。

低予算なら「資格で勉強の範囲を作り、作品集で実技を示す」のが合理的です。

| 資格 | 向く方向 | 低予算での判断 |
| --- | --- | --- |
| JAPRS サウンドレコーディング技術認定 | 音楽録音、mix、studio | 最初の本命。Cubaseでも理論と録音技術を学べる |
| MIDI検定3級 | DAW、MIDI、digital audioの基礎 | onlineで受けやすい小さな区切り。採用の決め手にはしない |
| JPPA 映像音響処理技術者 | MA、映像post-production | 映像の音へ進みたい時に追加 |
| JAPRS Pro Tools技術 / Avid認定 | Pro Tools中心の商用studio | 就職先の要件が見えてから。今はCubase制作を優先 |
| 舞台機構調整技能士 | PA、hall、stage sound | 実技と経験が必要。PA現場へ進んだ後に検討 |

2026年度のJAPRSサウンドレコーディング試験は高校卒業相当以上、90分四択、5,500円で、A〜Eのrankと分野別成績が交付されました。2026年7月5日の試験は終了済みです。2027年度の日程・料金・会場は未発表のため公式情報を待ちます。

2026年度の個人受験会場一覧に沖縄はなく、個人は会場を選べませんでした。次年度も沖縄がなければ、福岡等への旅費を含めて、資格の価値と比較します。試験勉強自体は無駄にならないため、先に作品制作と並行します。

## 2. JAPRSの学習範囲 {#japrs-scope}

公開範囲に合わせ、次を学びます。

1. 音響の基礎、聴覚、dB、stereo
2. 音響物理、電気、回路、digital技術
3. studio system、microphone、console、effect、monitor
4. stereo/multitrack/live recording、mix、mastering
5. surroundなど次世代音響
6. 音楽理論、楽器
7. 著作権
8. 制作史、staffの役割、用語
9. studioの遮音、音場、空調、電気、法規

このリポジトリは実技寄りです。試験固有の歴史、年表、規格、法規は、受験年度の公式テキストと公式問題集で補います。公開過去問題は本番同様に時間を測り、問題文をリポジトリへ転載しません。

## 3. 著作権と権利確認

最低限、次を区別します。

- song/compositionの著作権
- lyricsの著作権
- performanceに関する著作隣接権
- sound recording/masterに関する権利
- artwork、photo、videoの権利
- sample、loop、beat、font、plugin preset等のlicense

「自分がmixしたから自由に公開できる」とは限りません。バンド全員、作詞作曲者、演奏者、producer、studio、素材提供者の合意を確認します。

作品集へ載せる前の確認：

- [ ] 誰がmaster ownerか
- [ ] 公開範囲と期間
- [ ] full trackかexcerptか
- [ ] download可否
- [ ] credit表記
- [ ] 未発表曲の公開日
- [ ] 修正・削除依頼の窓口
- [ ] 練習素材の二次公開条件

## 4. 作品集3点

### A. 自分のバンド曲

担当範囲を明示：pre-production / recording / editing / mix / master。2入力でどう工夫したか、最も難しかった問題、artistの要望、revisionを示します。

### B. 他人の素材

利用許諾のあるmultitrackを使い、rough mixと自分のmixを比較。素材の再配布はせず、公開条件を確認。公開できなければ面接時のprivate試聴に限定します。

### C. 2〜3曲のmini-master

曲間の体感level、tonal balance、metadata、QCを示します。極端に大きくした結果ではなく、一貫した判断を見せます。

各作品の説明は次の順です。

`目的 → 制約 → 問題 → 仮説 → 処理 → level-matched検証 → artist feedback → 結果 → 次回の改善`

## 5. 仕事の入口

### 録音studio

assistantから始めることが多く、求められるのはsignal flow、microphone/cable、session準備、file管理、掃除、時間厳守、演者への配慮、失敗の即時報告です。Pro Toolsを使う職場が多いため、応募先が決まった段階で基礎操作を追加します。

### live PA / hall

沖縄ではevent、hall、hotel、舞台、配信などを含む複合的な音響業務も候補です。録音mixとはsignal flowが共通しますが、feedback対策、安全、仕込み、撤収、無線、電源、現場連携が別途必要です。

### 映像MA / post-production

dialogue edit、noise reduction、sound effect、loudness、picture sync、delivery formatを学びます。進みたいと決めた時にJPPA資格を検討します。

### freelance / remote mix

最初からmastering専業を名乗るより、editing、vocal comp、mix prep、podcast/動画音声、demo mixなど小さく明確な仕事から始めます。revision回数、納期、納品形式、credit、料金、backup期間を事前に書きます。

## 6. 沖縄での90日行動計画

### 1〜30日

- Week 1〜4を進める。
- 自バンド1曲のpre-productionとtest recording。
- Cubase対応の地元lessonは無料体験または単発だけ試し、継続契約は効果を確認してから。
- studio、live house、event会社を10件list化。

### 31〜60日

- 自バンド曲のtrackingとediting。
- 地元liveでPA卓、stage、転換を観察し、迷惑にならない時に見学・手伝いの可否を尋ねる。
- 公開練習素材を1曲mix。

### 61〜90日

- 自バンド曲Mix v1→band feedback→v2。
- ケーススタディ1本を完成。
- 必要なら1曲だけ有料添削を使い、指摘を次の曲へ転用。
- studio assistant、PA補助、配信音声、映像制作会社など、資格必須でない入口へ応募。

## 7. 応募前チェック

- [ ] 作品2〜3点を3分以内で案内できる
- [ ] 自分の担当範囲と他人の功績を区別している
- [ ] signal flowを紙に描ける
- [ ] 48V、balanced cable、gain、latency、backupを説明できる
- [ ] 失敗例と再発防止を話せる
- [ ] client revisionへ感情的にならず対応できる
- [ ] 夜間・長時間・運搬・普通免許など現場条件を確認した
- [ ] 求人ごとに作品順と自己紹介を変えた
