# 録音・ミックス・マスタリング独学ロードマップ

Windows / Cubase Pro 14 / MOTU M2 を使い、専門学校に通わずに次の2つを同時に進めるための教材です。

1. JAPRS「サウンドレコーディング技術認定試験」の基礎固め
2. バンド録音を就職・受注につながる作品集へ育てること

このリポジトリの教材はオリジナルです。JAPRS公式教材や過去問題の転載ではありません。試験固有の用語・歴史・規格は、必ず受験年度の公式教材でも確認してください。

## 必要なもの

- Windows PC
- Cubase Pro 14
- MOTU M2と純正ASIOドライバー
- 手持ちのヘッドホンまたはモニタースピーカー
- 自分で権利を持つ演奏素材、または利用条件を確認した練習用マルチトラック
- 週5時間ほど

マイクを持っていない場合も、第1〜3週とミックス課題は始められます。録音課題は、スマートフォンで録った音やMOTU M2のライン/DI入力でも代用できます。

## 今日やること（約45分）

1. `ROADMAP.md` を開き、第1週の欄に開始日を書く。
2. Cubaseで48 kHz / 24 bitの空プロジェクトを作る。
3. MOTU M2 ASIOを選び、モノ入力2本とステレオ出力1本を設定する。
4. 10秒の音を録り、`BandName_Song_BPM_SampleRate_Date` の形式で保存する。
5. `templates/study-log.md` に、できたことと分からなかったことを1行ずつ書く。

## 作品集の合格ライン

資格だけでなく、次の3点を作ることを目標にします。

1. 生演奏の録音・編集・ミックス（自分のバンド）
2. 他人が録った素材のミックス（利用許諾のある素材）
3. 2〜3曲を音量感と音色のまとまりまで整えたミニマスタリング

各作品には、音源だけでなく「目的」「録音環境」「信号経路」「問題」「判断」「修正前後」「クレジット」を1ページで添えます。テンプレートは `templates/portfolio-case-study.md` にあります。

## GitHubでの使い方

- GitHub Pagesで教材を読む場合、この教材リポジトリはPublicにします。未発表曲、WAV、Cubaseプロジェクト、個人情報を含むメモは、別のPrivateリポジトリまたは非公開ストレージに分けます。
- 公開サイトでは、全文検索、スマートフォン対応のメニュー、12週間の進捗保存を利用できます。進捗はブラウザ内だけに保存され、別端末とは自動同期されません。
- 毎週、チェック欄・学習ログ・ミックス判断を更新してコミットします。
- CubaseプロジェクトやWAVは巨大で差分管理に向きません。既定ではGit管理から除外し、PCと別のバックアップ先に二重保存します。
- 市販曲、無断取得したステム、公式問題集のスキャンはアップロードしません。
- 質問はGitHub Issueに1件1テーマで残すと、後から同じミスを検索できます。

サイトをローカルで確認する場合は、Node.js 20以上で `npm install`、`npm run docs:dev` を実行します。`main` ブランチへPushすると、GitHub ActionsがVitePressをビルドしてPagesへ公開します。

### GitHub Pagesの初回設定

1. GitHub Freeを使う場合は、この教材リポジトリをPublicにする。
2. リポジトリの `Settings` → `Pages` を開く。
3. `Build and deployment` の `Source` で `GitHub Actions` を選ぶ。
4. `Actions` タブの `Deploy learning site to GitHub Pages` が完了したら、表示されたURLを開く。

初回だけこの設定が必要です。以後は `main` へのPushで自動更新されます。

## 大事な安全ルール

- 耳鳴りや痛みが出る音量で練習しない。
- 48Vファンタム電源は、接続機器が対応することを確認する。monitor音量とinput gainを下げ、接続後にON、OFF後は放電を待ってから抜く。
- ケーブルの抜き差しは、monitor音量とinput gainを下げてから行う。
- マスタリングで「数値を合わせるためだけ」に音を潰さない。配信サービスごとに仕様が変わるため、納品先の最新仕様を都度確認する。
