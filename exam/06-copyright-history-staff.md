# 06 音楽著作権・録音史・制作スタッフ

## この章の目標

- 楽曲、歌詞、実演、recording masterに関わる権利を分けて説明する。
- 著作者人格権、著作権（財産権）、著作隣接権を主体と利用行為から分類する。
- 日本の保護期間の原則を計算し、古い作品・外国作品では個別確認が必要だと判断する。
- 私的使用、引用、教育、非営利・無料の上演などの制限規定を「無条件の自由利用」と誤解しない。
- 記録媒体と制作技術の変化を、cylinder、disc、magnetic、multitrack、digitalの流れで説明する。
- producer、engineer、assistant、mastering engineerなどの責任範囲を区別する。

::: danger 法律について
この章は、2026年7月15日時点の日本法と文化庁の令和8年度著作権テキストを基にした**教育用の一般解説**です。法的助言ではありません。実際の公開、契約、sample利用、紛争、外国作品、古い作品の保護期間は、権利管理団体・弁護士等の専門家および最新の法令で個別に確認してください。
:::

この章も公式教材や公開過去問題の転載ではなく、公開出題範囲で求められる概念を独自の例で学ぶ教材です。

## 1. 一つの曲に複数の権利がある

完成音源を一つのfileとして見ても、法律上・契約上の対象は一つとは限りません。

```text
曲・歌詞（著作物）
  ├─ 作曲者・作詞者などの著作者の権利
  └─ publisherや管理事業者が管理する場合がある

演奏・歌唱（実演）
  └─ musician・singerなど実演家の著作隣接権

固定されたrecording（レコード／原盤）
  └─ 音を最初に固定したレコード製作者の著作隣接権

契約上のmaster ownership、収益分配、credit
  └─ 法律上の権利と重なるが、同じ概念ではない
```

### 具体例

自分のbandが他人の曲をcoverして新しく録音した場合：

- 元の曲・歌詞について著作者側の権利がある。
- 新しい演奏についてband memberの実演家の権利が生じ得る。
- 新しく音を固定した主体にrecord producerの権利が生じ得る。
- 元の市販音源を使っていないなら、その市販masterそのものは複製していない。
- ただし公開、配信、編曲、映像への使用など、行う利用ごとに許諾や手続を確認する。

**public domainの曲**でも、他人が後年に録音したmasterや編曲は別に保護され得ます。「作曲者の保護期間が終わった」だけで、市販音源を自由にsampleできるわけではありません。

## 2. 著作物と著作者

日本の著作権法では、著作物は大まかに「思想または感情を創作的に表現し、文芸・学術・美術・音楽の範囲に属するもの」です。

- ideaだけではなく、創作的な**表現**が対象。
- 単なる事実やdata、ありふれた表現は著作物に当たらない場合がある。
- 音楽の著作物は、原則として楽譜や録音へ固定されていなくても成立し得る。
- 権利取得のための登録を原則必要としない**無方式主義**。創作時に権利が発生する。

通常、実際に創作した個人が著作者です。ただし一定の条件を満たす職務著作、映画の著作物などには特則があります。「依頼し、料金を払った人が必ず著作者になる」とは限りません。譲渡範囲や利用許諾を契約で確認します。

## 3. 著作者人格権と著作権（財産権）

### 著作者人格権

著作者の精神的利益を守る、著作者に専属する権利です。譲渡できません。

| 権利 | 中心となる内容 | 音楽制作の例 |
| --- | --- | --- |
| 公表権 | 未公表作品を公表するか決める | 未発表demoを無断公開しない |
| 氏名表示権 | 名前を出すか、どの名前にするか決める | 本名、artist名、無名の選択 |
| 同一性保持権 | 意に反する内容・題号の改変を受けない | 曲を勝手に切り刻み別題で出さない |

著作者が死亡すると人格権自体は消滅しますが、死後も原則として、存命なら人格権侵害となる行為をしてはならない旨の規定があります。

### 著作権（財産権）

利用方法ごとの権利の束です。譲渡・相続の対象になり得ます。

| 権利 | 利用行為の中心 | 音楽での例 |
| --- | --- | --- |
| 複製権 | copy・録音・録画など | 曲をrecording fileへ固定、CD複製 |
| 上演権・演奏権 | 公衆へ上演・演奏 | live演奏、店舗でrecordingを再生 |
| 公衆送信権（送信可能化を含む） | 放送・配信、requestに応じ送信できる状態へ置く | streaming、web公開、serverへuploadして公開待機 |
| 譲渡権 | 複製物を公衆へ譲渡 | copyした媒体を販売 |
| 貸与権 | 複製物を公衆へ貸す | record rental |
| 翻訳権・翻案権等 | 編曲、翻訳など二次的著作物を作る | 創作性を伴う編曲、歌詞翻訳 |
| 二次的著作物の利用に関する原著作者の権利 | 二次的著作物の利用にも関与 | 編曲版を配信する |

**同期権（synchronization right）**は映像へ音楽を合わせるbusiness上の呼び方として使われますが、日本の著作権法に「同期権」という一個の名前の権利があるわけではありません。実際には複製、翻案、公衆送信、原盤利用など、企画の行為に応じた権利処理をします。

## 4. 著作隣接権

著作物を公衆へ伝える重要な役割を担う者に与えられる権利です。日本では次の四者が中心です。

1. 実演家
2. レコード製作者
3. 放送事業者
4. 有線放送事業者

著作者は作品を創作した人、実演家等は作品を演じ、固定し、伝達する側です。著作者は「著作隣接権を持つ四者」の一つではありません。

### 実演家

歌手、演奏者、俳優、指揮者など、実演を行う人です。

- 実演家人格権：氏名表示権、同一性保持権。著作者と異なり公表権はありません。
- 財産的な権利：録音・録画、放送・有線放送、送信可能化、譲渡などに関する権利。
- 一定の放送二次使用、貸与等では報酬・補償を受ける仕組みがある。

録音を許諾した後の利用には特則があり、すべての後続copyについて同じ許諾権を行使できるとは限りません。だからこそ、master利用、配信、広告、期間、地域、二次利用、報酬を契約で具体化します。

### レコード製作者

著作権法上の**レコード製作者**は「レコードに固定されている音を最初に固定した者」です。日常語の「producer」という肩書だけで自動的に決まるとは限りません。誰が企画し、費用を負担し、録音・原盤制作へ責任を持ったか、契約と実態は主体を確認するための重要な材料になりますが、法定義そのものとは分けて覚えます。

主に複製、送信可能化、譲渡、貸与等に関する権利と、一定の報酬請求の仕組みがあります。著作権法上の「レコード」はCDという物体だけを意味せず、音を固定したものを広く扱う概念です。

### 放送事業者・有線放送事業者

放送・有線放送を録音録画する複製、再放送・再有線放送、送信可能化、特別な大型装置を用いるtelevision放送の公の伝達などに関する権利があります。貸与権は、これらの事業者に共通する代表的な権利ではありません。

## 5. 保護期間

### 著作権（財産権）の原則

| 著作物 | 原則的な保護期間 |
| --- | --- |
| 個人の実名・周知の変名 | 著作者の生存中＋死後70年 |
| 無名・変名（周知の変名を除く） | 公表後70年 |
| 団体名義 | 公表後70年 |
| 映画の著作物 | 公表後70年 |

期間は死亡・公表等があった年の**翌年1月1日から数えます**。

例：著作者が2020年6月に死亡した場合、原則として2021年1月1日から70年を数え、2090年12月31日まで保護され、2091年1月1日に期間満了後の状態になります。

無名・変名、団体名義、映画には、期間内に公表されなかった場合や著作者の死亡時期が明らかになった場合などの細則があります。

### 著作隣接権（財産権）

| 対象 | 保護の終わりの原則 |
| --- | --- |
| 実演 | 実演後70年 |
| レコード | 発行後70年。期間内に発行されない場合は固定後70年 |
| 放送 | 放送後50年 |
| 有線放送 | 有線放送後50年 |

これらも該当年の翌年1月1日から数えます。実演家人格権は実演家の生存中に存続し、死後の人格的利益にも別の保護規定があります。

### 古い作品・外国作品に注意

- 法改正時にすでに消滅していた権利が、延長により当然復活するわけではない。
- 旧著作権法の経過措置により、単純な「西暦＋70」にならないことがある。
- 外国作品には条約、内国民待遇、相互主義、戦時加算等の検討が必要な場合がある。
- 著作物の期間と、その演奏・recordingの隣接権の期間は別々に満了する。

試験問題では与えられた条件を読み、死亡年・公表年・実演年・発行年のどれを起点にするか選びます。実務では専門窓口に確認します。

## 6. 権利制限規定

日本法には米国型の包括的な「fair use」条項があるわけではなく、目的・主体・方法ごとの制限規定を確認します。「非営利だから何でも自由」でもありません。

### 私的使用のための複製

家庭内など限られた範囲で、仕事以外の使用を目的として、原則として使用する本人が複製する場合の規定です。

- webへの公開・共有は私的使用ではない。
- 会社や仕事で使うcopyは原則として私的使用ではない。
- 違法配信と知りながら一定の著作物をdownloadする場合など、対象外となる条件がある。
- copy protection回避等にも別の制約がある。

### 引用

公表された著作物を、公正な慣行に合致し、報道・批評・研究等の目的上正当な範囲で引用する規定です。一般に、引用部分の明確化、主従関係、必要性、出所明示などを確認します。「出典を書けば全文転載してよい」という制度ではありません。

### 学校その他の教育機関

授業過程で必要な範囲の複製・公衆送信には規定がありますが、教育機関、授業主体、必要限度、権利者の利益を不当に害しないこと、補償金制度等の条件があります。「学習目的」と名付けた一般web公開が自動的に適法になるわけではありません。

### 非営利・無料の上演・演奏等

公表済み著作物の上演、演奏、上映、口述について、主に次をすべて満たす時の例外です。

1. 営利を目的としない。
2. 聴衆・観衆から料金を受けない。
3. 出演者等に報酬を支払わない。
4. 慣行がある場合は出所を明示する。

この規定は、recordingの複製・配布やinternet配信を一括して自由にするものではありません。charity目的でも入場料や出演報酬があれば、条件を外れる可能性があります。

## 7. band制作の権利確認

### 録音前

- [ ] 作詞、作曲、編曲の担当と持分
- [ ] member以外のsession musicianの実演利用
- [ ] producer、studio、engineerのcreditと報酬
- [ ] sample、loop、beat、preset、譜面のlicense
- [ ] cover曲・翻訳詞・替え歌・創作性を伴う編曲の手続（変更が小さければ常に自由、という意味ではなく個別判断）
- [ ] 写真、artwork、logo、videoの権利と肖像

### 公開前

- [ ] 誰がmasterを管理し、配信登録するか
- [ ] 配信、download、CD、SNS、広告、映像同期の範囲
- [ ] 期間、地域、独占・非独占、再許諾
- [ ] 収益、費用回収、royalty、会計報告
- [ ] credit表記とartist名
- [ ] 未発表版、stem、multitrackの保管・再利用
- [ ] 契約終了、削除、member脱退時の扱い

### sampleを使う時

市販recordingの一部を使うと、少なくとも元の曲側と元のmaster側の検討が必要です。短ければ必ず自由、加工して分からなければ自由、無料公開なら自由、という一律の秒数ruleはありません。許諾可能なlibrary素材でも、再配布禁止、Content ID、商用範囲、credit条件をlicense原文で確認します。

## 8. 録音・再生mediaの歴史

歴史は年号だけでなく、「何を可能にしたか」で覚えます。

| 時期 | 主な出来事 | 制作への意味 |
| --- | --- | --- |
| 1857 | phonautographが音の振動を線として記録 | 音を可視化したが、当初は再生目的ではない |
| 1877 | Edisonのphonograph | cylinderへ記録し、再生できる機械 |
| 1887ごろ | Berlinerのgramophoneと平円盤 | 横振動のdiscと複製・量産へつながる |
| 19世紀末〜1920年代前半 | acoustic recording | hornで音響energyを直接記録。balanceは演奏位置に強く依存 |
| 1906以後 | triode真空管と増幅技術 | microphone信号の増幅、電気録音・放送の基盤 |
| 1920年代半ば | electrical recordingの普及 | microphone、amplifierで帯域・level・配置の自由度が向上 |
| 1898〜1930年代 | magnetic wire/tapeの発明・実用化 | 消去、再録音、編集、長時間記録の道 |
| 1940年代後半 | vinyl LP、magnetic tapeの普及 | 長時間・低noise、tape spliceによる編集 |
| 1950年代 | stereo disc、overdub、multitrackの発展 | 空間表現と演奏の重ね録り |
| 1960〜70年代 | 8/16/24-track、大型console | trackごとの処理、mixdownという工程が定着 |
| 1970年代 | PCM digital recordingが実用段階へ | copy・編集・記録をsample値として扱う |
| 1982 | Compact Discの商用化 | optical digital mediaが家庭へ普及 |
| 1980〜90年代 | MIDI、hard-disk recording、DAW | 非破壊編集、automation、project recall |
| 2000年代以後 | file配信、streaming、network制作 | 物理mediaからmetadata・権利・version管理へ比重が移る |

### 縦振動と横振動

- **vertical / hill-and-dale recording（縦振動）**：溝の深さ方向へ変化を刻む。
- **lateral recording（横振動）**：溝を左右方向へ変化させる。

Edison系cylinderや一部discでは縦振動、Berlinerのgramophone discでは横振動が重要な方式となりました。stereo discでは溝の両壁へ左右channelを組み合わせて記録する45/45方式が広く用いられました。

### magnetic recording

磁気recordingではheadと媒体の相対運動により、音声信号に応じた磁化を残します。

- erase head：以前の磁化を消去。
- record head：信号を媒体へ記録。
- reproduce/playback head：磁化変化を電気信号へ戻す。
- bias：高周波信号を加え、磁気特性の非線形を改善する。
- tape speed：一般に速いほど高域・noise・記録時間などの関係が変わる。

multitrack tapeでは、同じ幅を多くのtrackへ分割すると1 track当たりの幅は狭くなります。一方、overdub、個別処理、mix revisionの自由度が増えました。

## 9. 日本の制作史を時代で見る

| 時代 | 大きな流れ |
| --- | --- |
| 明治 | 西洋音楽・楽器とともに蓄音機・record文化が入り、国内の演奏・販売・製造基盤が形成される |
| 大正 | disc recordが大衆化し、1925年に日本のradio放送が始まる。演奏会場とrecord以外の伝達路が拡大 |
| 昭和初期 | electrical recording、radio、talkieが進み、microphone・amplifierを扱う制作staffの専門性が高まる |
| 戦後〜高度成長期 | LP、magnetic tape、stereo、放送、studio産業が拡大。編集とmultitrack制作が発展 |
| 昭和後期 | 24-track、synthesizer、digital PCM、CD、MIDIが制作と流通を変える |
| 平成以後 | DAW、file、internet、streamingへ。小規模studioでも高度な編集が可能になる一方、dataと権利管理が重要になる |

年表問題では、発明年と日本での普及年、試作と商品化、monoとstereoを混同しないようにします。資料により「発明」「公開実験」「発売」のどれを節目とするかが違います。

## 10. 制作staffの役割

肩書は現場規模で重なります。試験では役割の中心を、現場では**誰が最終決定するか**を確認します。

### 企画・音楽面

| staff | 主な責任 |
| --- | --- |
| executive producer | 予算・事業・最終承認などproject上位責任 |
| A&R | artist発掘、repertoire、labelとの企画調整 |
| music producer / record producer | 作品の方向、選曲、演奏、制作全体の判断 |
| director | session進行、take判断、artistと技術staffの橋渡し。現場によりproducerと重なる |
| composer / lyricist | 作曲 / 作詞 |
| arranger / orchestrator | 編曲、編成、楽器への配分 |
| conductor / music director | ensembleのtempo、balance、解釈を統率 |
| contractor / coordinator | musician手配、schedule、連絡、書類 |
| music copyist / librarian | score・part譜の作成、配布、revision管理 |

### 技術面

| staff | 主な責任 |
| --- | --- |
| recording engineer | 収音、signal path、recording system、技術判断 |
| balance / mix engineer | track間のbalanceと完成mix |
| assistant engineer | setup、patch、session、take、file、撤収を支え、確認を二重化 |
| technical / maintenance engineer | 機器保守、配線、calibration、障害対応 |
| mastering engineer | final master、曲間、媒体・format、QC |
| studio manager | 施設、予約、staff、予算、安全の運営 |
| editor | comp、timing、noise、dialogue等の編集 |
| PA FOH engineer | 客席向けsound reinforcement mix |
| monitor engineer | stage上の演者向けmonitor mix |
| broadcast mixer | 放送用balance、回線、基準level、送出連携 |
| post-production mixer | 映像に対するdialogue、music、effectsの最終mix |

### assistantが先回りする項目

- input list、mic、stand、cable、DI、headphoneの数量。
- phantom、patch、preamp gain、clock、sample rate。
- track name、色、record enable、folder、marker。
- talkback、cue、click、latency。
- take番号、NG理由、採用候補、session log。
- save new version、backup、checksum、納品copy。
- 飲食、転倒、聴覚、電源、避難経路などの安全。

assistantは独断でartistのtakeを消したり、patchを変更したりしません。異常を隠さず、影響と現状を短く報告します。

## 11. 制作工程と責任の受け渡し

```text
企画・契約
  ↓  producer / A&R / artist
pre-production・arrangement
  ↓  producer / arranger / director
tracking
  ↓  recording engineer / assistant / musicians
editing・overdub
  ↓  producer / editor / engineer
mixdown
  ↓  mix engineer / producer / artist approval
mastering
  ↓  mastering engineer / label or client approval
distribution・archive
     metadata / rights / delivery / backup
```

各工程で `input → decision owner → deliverable → approval → archive` を記録すると、技術問題と権利問題を分けて追跡できます。

## 理解確認

1. 曲、実演、masterの三層に関わる主な権利者を挙げてください。
2. 著作者人格権の三つと、実演家人格権の二つを答えてください。
3. 著作権（財産権）は譲渡できますか。著作者人格権はどうですか。
4. 著作隣接権を持つ四者を答えてください。
5. 著作者が2024年に死亡した場合、原則として何年末まで保護されますか。
6. 2020年に行われた実演の隣接権は、原則として何年末までですか。
7. 2020年に行われた放送の隣接権は、原則として何年末までですか。
8. 非営利・無料の演奏に関する主な条件を三つ挙げてください。
9. public domainの曲を演奏した2025年の市販recordingを、無許諾でsampleしてよいですか。理由も述べてください。
10. cover recordingと元の市販masterの関係を説明してください。
11. cylinder、disc、magnetic tape、multitrack、DAWを古い順に並べてください。
12. 横振動と縦振動は、disc grooveのどの方向の変化ですか。
13. record head、reproduce head、erase headの役割を答えてください。
14. mix engineerとmastering engineerの判断対象を区別してください。
15. assistant engineerがsession終了直後に行うdata作業を三つ挙げてください。

<details>
<summary>解答例</summary>

1. 曲・歌詞は作詞作曲者等、実演は実演家、recordingは最初に固定したレコード製作者です。契約により管理・帰属は別途確認します。
2. 著作者は公表・氏名表示・同一性保持、実演家は氏名表示・同一性保持です。
3. 財産権は譲渡可能、人格権は著作者に専属し譲渡できません。
4. 実演家、レコード製作者、放送事業者、有線放送事業者です。
5. 翌2025年から70年を数え、2094年12月31日までが原則です。
6. 翌2021年から70年を数え、2090年12月31日までが原則です。
7. 翌2021年から50年を数え、2070年12月31日までが原則です。
8. 非営利、観客から料金を取らない、出演者等へ報酬を払わない、すでに公表された著作物、などです。
9. 原則として自由とは言えません。曲の著作権期間と、2025年の実演・masterの著作隣接権は別だからです。
10. 自分たちが新規演奏を固定すれば新しい実演・masterになりますが、元の曲の利用手続は別に必要です。元masterをsampleしない限り、その音源自体のcopyではありません。
11. cylinder → disc → magnetic tape → multitrack → DAWです。
12. 横振動は左右、縦振動は深さ方向です。
13. 記録、再生、以前の磁化の消去です。
14. mixはtrack間の関係を完成させ、masteringは完成mix・作品全体・納品formatを最終確認します。
15. fileを閉じる、別媒体へbackup、backupを開いて検証、version・take logを保存、などです。

</details>

## 章末チェック

- [ ] 曲・歌詞、実演、master、契約上の所有を分けて描ける
- [ ] 著作者人格権と財産権の権利名を分類できる
- [ ] 著作隣接権の四主体と代表的権利を説明できる
- [ ] 70年 / 50年の対象と翌年起算を使って計算できる
- [ ] 古い作品・外国作品を単純計算だけで判断しない
- [ ] 私的使用、引用、教育、非営利上演の条件を説明できる
- [ ] cover、sample、映像同期の権利層を洗い出せる
- [ ] cylinder、disc、電気録音、magnetic、multitrack、digitalの順を説明できる
- [ ] 縦振動・横振動、三つのtape headを区別できる

- [ ] 工程ごとのdecision ownerとdeliverableを記録できる
