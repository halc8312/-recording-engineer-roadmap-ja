# JAPRS独学 日英用語集

公開出題範囲とこのサイトの各章を行き来するための、**独自表現による学習用索引**です。日本語・英語の一対一翻訳ではなく、録音現場で同じ英語を使う場合は英語表記を優先しています。短い説明だけで暗記せず、右端の章で条件・式・例を確認してください。

> [!TIP]
> 「日本語を見て英語と意味を言う」「英語を見て信号経路上の場所を指す」「似た語との差を一文で言う」の3方向で復習すると、選択肢の言い換えに強くなります。

## 現行法・規格に依存する語の確認先

**2026年7月15日確認。** 法令・規格・試験範囲は変わり得ます。著作権関連語は学習用に短くした説明であり、個別案件への法的助言ではありません。

- [e-Gov法令検索：著作権法](https://laws.e-gov.go.jp/law/345AC0000000048) — 「著作物」「著作者」「実演家」「レコード製作者」「録音」「複製」「公衆送信」「送信可能化」「二次的著作物」と著作隣接権の現行条文。
- [CRIC：著作権法](https://www.cric.or.jp/db/domestic/a1_index.html) — 条文構造を確認する補助。法的な最終確認はe-Govを優先。
- [RIAJ：著作権制度の概要](https://www.riaj.or.jp/copyright/about/) — 音源とレコード製作者の権利を確認する参考。
- [International ISRC Agency](https://isrc.ifpi.org/) — ISRCが録音・music videoの識別子であり、楽曲、商品、演奏者の識別子ではないことを確認。
- [JAPRS：2026年度公開出題範囲](https://www.japrs.or.jp/exam/soundrecording/range/) — 分野と索引語の範囲確認に使用。公式説明・用語集・問題は転載していません。

## 使い分けテスト

次の組を、それぞれ「何が違うか」一文で説明できれば索引として使えています。

- frequency / pitch / note name
- amplitude / level / loudness
- phase / polarity / delay
- absorption / insulation / diffusion
- resistance / reactance / impedance
- balanced / stereo / shield
- sample rate / bit depth / bit rate
- track / channel / bus
- timecode / word clock / genlock
- pair mic / multitrack / multichannel
- composition / performance / master recording
- author / performer / record producer / job-title producer

説明できない語は、表の右端から本文へ戻ってください。この用語集自体は、JAPRS公式教材・公式用語集の転載や代替ではありません。
