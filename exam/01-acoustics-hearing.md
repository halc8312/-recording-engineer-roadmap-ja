# 試験対策 01：音響・聴覚・音律

この章では、空気中の音を表す物理量と、人が感じる音を分けて考えます。録音では「メーター上は同じなのに違って聴こえる」「マイクを2本にしたら細くなった」「部屋の場所で低音が変わる」といったことが起きます。その理由を、式を暗記するだけでなく説明できる状態を目指します。

> [!IMPORTANT]
> この章はJAPRSの公開出題範囲と公開過去問題の概念傾向を参照し、ゼロから書いた独自教材です。公式教材や過去問題の本文・図・設問は転載していません。次年度の出題範囲は必ずJAPRS公式ページで確認してください。

## 学習目標

- 周波数、周期、音速、波長の関係を式と具体例で説明できる。
- dBが「比」を表す量であることを理解し、音圧・電力・基準付きレベルを区別できる。
- 位相、極性、干渉、コムフィルターの関係を録音の場面に結びつけられる。
- 反射、吸音、拡散、遮音、定在波、残響時間を区別できる。
- 外耳・中耳・内耳から脳までの聴覚経路を説明できる。
- 等ラウドネス、マスキング、臨界帯域がミックス判断へ与える影響を説明できる。
- 両耳間時間差・レベル差・耳介の手掛かりから音像定位を説明できる。
- 基音、倍音、部分音、うなり、音律を区別し、平均律の周波数を計算できる。

## この章の進め方

1. 各節を読み、式は「何を何で割るのか」まで声に出す。
2. 例題は答えを隠し、紙と電卓で先に解く。
3. 各節末の理解確認に答える。迷った語は本文へ戻る。
4. 最後に章末チェックを、資料を見ずに説明する。

計算では、特に断りがなければ室温付近の音速を `c = 343 m/s` とします。`log10` は常用対数、`log2` は底を2とする対数です。

## 1. 客観的な音と主観的な音

### 1.1 「音」という言葉の2つの意味

音には少なくとも2つの見方があります。

| 見方 | 意味 | 例 |
| --- | --- | --- |
| 客観的・物理的な音 | 媒質中を伝わる圧力や粒子運動の変化 | マイクが受ける空気の音圧変化 |
| 主観的・知覚的な音 | 聴覚系と脳が作る感覚 | 高い、低い、大きい、明るい、近い |

マイクは「迫力」や「心地よさ」を直接測っているのではありません。時間とともに変化する物理量を電気信号へ変換しています。一方、人はその信号を周波数、持続時間、前後の音、左右の耳への届き方、経験などと合わせて解釈します。

対応は一対一ではありません。

| 主な物理量 | 関係する知覚 | 一対一にならない理由 |
| --- | --- | --- |
| 周波数 | 音の高さ（pitch） | 倍音、音量、持続時間にも影響される |
| 音圧・音響強度 | 大きさ（loudness） | 周波数、時間、個人差にも影響される |
| スペクトル、包絡、過渡成分 | 音色（timbre） | 発音方法や時間変化も重要 |
| 両耳間の時間差・レベル差 | 方向、広がり | 反射、頭部・耳介、視覚にも影響される |

したがって「3 dB上げれば必ず同じだけ大きく感じる」「同じ周波数特性なら同じ音色」という断定はできません。測定値と聴感の両方を扱うのが録音エンジニアの仕事です。

### 理解確認 1

1. マイクが直接測っていないものを、「音圧」「周波数」「心地よさ」から1つ選んでください。
2. 周波数が同じでも音色が違う主な理由を2つ挙げてください。

<details>
<summary>答え</summary>

1. 心地よさ。マイクは物理的な変化を電気信号へ変換しますが、心地よさは聴覚と脳による評価です。
2. 例：倍音の構成、ノイズ成分、立ち上がり、減衰、時間変化、演奏法。2つ説明できれば十分です。

</details>

## 2. 波、周波数、周期、音速、波長

### 2.1 空気中の音は縦波

空気中の音は、空気の粒子が進行方向とほぼ平行に往復し、圧縮と膨張が隣へ伝わる**縦波**です。空気そのものが音源から耳まで一方向に飛び続けるわけではありません。

```
スピーカー →  密  疎  密  疎  →  マイク
               圧縮    膨張
粒子の往復  ↔ ↔ ↔ ↔ ↔
波の進行    ─────────→
```

真空には空気のような媒質がないため、通常の空気伝搬音は進めません。固体や水中では、それぞれの媒質に応じた速度と波の種類で音が伝わります。

### 2.2 正弦波を表す量

単一周波数の理想的な正弦波は、次の量で記述できます。

| 量 | 記号 | 単位 | 意味 |
| --- | --- | --- | --- |
| 周波数 | `f` | Hz | 1秒あたりの周期数 |
| 周期 | `T` | s | 1周期にかかる時間 |
| 振幅 | `A` | 対象による | 波の大きさ。音圧ならPa、電圧ならV |
| 位相 | `φ` | ° または rad | 周期上の位置 |
| 音速 | `c` | m/s | 波が媒質中を進む速さ |
| 波長 | `λ` | m | 空間上の1周期の長さ |

空気中の**音圧**は、大気圧そのものではなく、音によって大気圧の周りに生じる微小な圧力変化です。単位はPaです。時間変化する波の大きさにはpeak、peak-to-peak、実効値（RMS）など複数の表し方があるため、数値を比べる時はどれかを確認します。正弦波では次の関係です。

```
pRMS = pPeak / sqrt(2)
```

**音響パワー**は音源が単位時間に放射する音響エネルギーで、単位はWです。**音響強度**は単位面積を通過する音響パワーで、単位はW/m²です。音圧は場所で測る圧力、音響パワーは音源側の放射量、音響強度はエネルギーの流れと区別します。自由進行平面波を理想化すると、実効音圧 `pRMS`、空気密度 `ρ`、音速 `c` の間に次の関係があります。

```
I = pRMS^2 / (ρc)
```

この二乗関係が、音圧比では `20 log10`、強度比では `10 log10` を使う理由につながります。

基本式は次の2つです。

```
T = 1 / f
λ = c / f
```

周波数が2倍なら周期と波長は半分になります。周波数は音源が作る振動の速さ、音速は媒質の状態で決まる伝搬速度です。同じ室内で周波数が変わっても、音速がそれに合わせて2倍になるわけではありません。

### 2.3 音速

乾燥空気中の音速は温度などで変化します。常温付近の概算には次を使えます。

```
c ≈ 331.3 + 0.606θ
```

`θ` は摂氏温度です。20 ℃なら `c ≈ 343.4 m/s` です。湿度や気圧の影響もありますが、試験の基礎計算や小規模録音の見積もりでは、問題文に指定がなければ `343 m/s` を使うことが一般的です。

### 例題 2-A：周期と波長

1 kHzの正弦波について、周期と波長を求めます。

```
f = 1,000 Hz
T = 1 / 1,000 = 0.001 s = 1 ms
λ = 343 / 1,000 = 0.343 m = 34.3 cm
```

同じ方法で100 Hzなら、周期は10 ms、波長は3.43 mです。低音の波長が部屋の寸法に近くなりやすいことが、後で扱う定在波と関係します。

### 波長の目安

| 周波数 | 周期 | 波長（`c = 343 m/s`） | 録音上の感覚 |
| ---: | ---: | ---: | --- |
| 20 Hz | 50 ms | 17.15 m | 小部屋よりかなり長い |
| 50 Hz | 20 ms | 6.86 m | 部屋寸法と強く関係しやすい |
| 100 Hz | 10 ms | 3.43 m | ベース、キックの低域 |
| 1 kHz | 1 ms | 34.3 cm | 声の明瞭さにも関係する帯域 |
| 10 kHz | 0.1 ms | 3.43 cm | 小さな物体でも反射・遮蔽されやすい |

### 2.4 オクターブ

周波数比が2:1の間隔を1オクターブと呼びます。100 Hzの1オクターブ上は200 Hz、1オクターブ下は50 Hzです。1/3オクターブでは、隣接する中心周波数の比が理想的には `2^(1/3) ≈ 1.260` になります。

オクターブは「100 Hz増える」という一定差ではなく**一定比**です。100→200 Hzも1 kHz→2 kHzも1オクターブです。

### 理解確認 2

1. 250 Hzの周期は何msですか。
2. `c = 343 m/s` のとき、50 Hzの波長は何mですか。
3. 500 Hzの1オクターブ上と下は何Hzですか。
4. 同じ空気中で周波数が2倍になると、音速と波長はどうなりますか。

<details>
<summary>答え</summary>

1. `T = 1/250 = 0.004 s = 4 ms`。
2. `λ = 343/50 = 6.86 m`。
3. 上は1,000 Hz、下は250 Hz。
4. 音速はほぼ同じで、波長が半分になります。

</details>

## 3. レベルとデシベル

### 3.1 dBは比を対数で表す

デシベル（dB）は、それだけでは音圧や電圧の絶対値ではなく、2つの量の**比**を対数で表したものです。

電力・音響強度のように二乗前の量を直接比べる場合：

```
L = 10 log10(P2 / P1)
```

音圧・電圧のように、同じインピーダンス条件で電力が振幅の二乗に比例する量を比べる場合：

```
L = 20 log10(A2 / A1)
```

係数10と20を取り違えないために、「何の比を求めているか」を先に書きます。

| 変化 | 振幅・音圧・電圧比 | 電力・強度比 |
| --- | ---: | ---: |
| +3.01 dB | 約1.413倍 | 2倍 |
| +6.02 dB | 2倍 | 約4倍 |
| +10 dB | 約3.162倍 | 10倍 |
| +20 dB | 10倍 | 100倍 |
| -6.02 dB | 1/2 | 約1/4 |

### 3.2 基準付きレベル

基準値を決めると、絶対的な大きさをdBで表せます。

| 表記 | 0 dBの基準 | 主な用途 |
| --- | --- | --- |
| dB SPL | `20 µPa` の音圧（空気中） | 音圧レベル |
| dBu | `0.775 Vrms` | 業務音響の電圧レベル |
| dBV | `1 Vrms` | 機器の電圧レベル |
| dBFS | デジタル系で表せるfull scale | DAW、PCMの信号レベル |

音圧レベルは次で表します。

```
Lp = 20 log10(p / p0)
p0 = 20 µPa
```

`0 dB SPL` は「無音」ではなく、基準音圧と同じレベルです。`0 dBFS` はデジタルfull scaleであり、`0 dB SPL` とは意味も基準も違います。dBFSの信号を何dB SPLで再生するかは、D/A、アンプ、スピーカー、距離、校正で変わります。

### 例題 3-A：音圧が2倍

```
20 log10(2) ≈ 20 × 0.3010 = 6.02 dB
```

したがって、音圧が2倍なら約+6 dBです。「電力が2倍」とは条件が違い、こちらは約+3 dBです。

### 例題 3-B：94 dB SPLの音圧

`Lp = 94 dB SPL` の音圧 `p` を求めます。

```
94 = 20 log10(p / 20 µPa)
p / 20 µPa = 10^(94/20) ≈ 50,119
p ≈ 1.00 Pa
```

このため、1 Paは約94 dB SPLとしてよく使われます。

### 3.3 レベルの加算

dB値をそのまま足してはいけません。相関のない音の平均電力を足すなら、線形の電力へ戻してから加えます。

```
Ltotal = 10 log10(10^(L1/10) + 10^(L2/10) + ...)
```

相関のない同レベル音源を2つ加えると約+3 dB、4つなら約+6 dBです。一方、同じ波形が完全に同位相で重なり音圧が2倍になれば約+6 dBです。位相関係によっては逆に減少します。

### 例題 3-C：80 dBと74 dBを加える

```
Ltotal = 10 log10(10^(80/10) + 10^(74/10))
       ≈ 80.97 dB
```

大きい方の80 dBに74 dBを足しても154 dBにはなりません。差が6 dBある音を加えた増加は約1 dBです。

### 3.4 距離による減衰

自由音場の点音源を理想化すると、音響強度は距離の二乗に反比例し、音圧は距離に反比例します。

```
ΔLp = 20 log10(r1 / r2)
```

距離を1 mから2 mへ倍にすると、`20 log10(1/2) ≈ -6.02 dB` です。ただし、室内では反射音が加わり、近接場、指向性、線音源、大きな音源などではこの単純な結果から外れます。

### 3.5 周波数重み付け

A特性、C特性などは、測定値に周波数ごとの重みを付ける方法です。`dB(A)` は無補正のdB SPLと同じではありません。A特性は人の聴感の一面を近似するため騒音評価で広く使われますが、音楽の音質や低域を完全に表す万能指標ではありません。

### 理解確認 3

1. 電力が10倍なら何dBですか。
2. 音圧が1/4なら何dBですか。
3. 相関のない同レベルの音を2つ加えると、平均レベルは約何dB増えますか。
4. `-18 dBFS` の信号へ線形な+12 dBのgainを加えると、同じpeakは何dBFSですか。
5. `0 dB SPL` と `0 dBFS` の違いを一文で説明してください。

<details>
<summary>答え</summary>

1. `10 log10(10) = +10 dB`。
2. `20 log10(1/4) ≈ -12.04 dB`。
3. 約+3.01 dB。
4. `-6 dBFS`。後段の非線形処理やtrue peakは考えない条件です。
5. `0 dB SPL` は20 µPaを基準とする音圧レベル、`0 dBFS` はデジタルfull scaleを基準とする信号レベルです。

</details>

## 4. 位相、極性、干渉

### 4.1 位相と時間差

位相は周期上の位置を角度で表したものです。1周期が360°、半周期が180°、1/4周期が90°です。同じ周波数について、時間差 `Δt` と位相差 `Δφ` の関係は次です。

```
Δφ = 360° × f × Δt
```

同じ1 msの遅れでも、1 kHzでは360°、500 Hzでは180°、250 Hzでは90°です。時間差による位相差は周波数ごとに変わります。

定常正弦波の位相角は通常360°ごとに同じ位置へ戻るため、360°は0°と等価に表せます。ただし、複雑な波形やtransientを1周期分遅らせれば、見かけの位相角が同じ周波数成分でも信号全体の到着時刻は遅れています。

### 4.2 極性反転は位相ずれと同じではない

**極性反転**は、波形の正負を全時刻で入れ替える操作です。理想的には全周波数成分へ一律に `-1` を掛けます。単一正弦波だけを見れば180°反転と同じ形に見えますが、時間遅延は周波数ごとに位相角が変わります。したがって、複雑な音に対して「極性」と「位相」は同義ではありません。

### 4.3 重ね合わせと干渉

線形な範囲では、複数の音圧は瞬間ごとに加算されます。

```
同じ波形・同位相      → 音圧が加わる
同じ波形・180°差      → 理想条件では打ち消す
一部の周波数だけ逆位相 → 周波数ごとに増減が変わる
```

現実の楽器音は多数の周波数と時間変化を含むため、完全に消えることはまれです。しかし2本のマイクへ同じ音が異なる時間で届くと、周波数ごとに山と谷が交互に生じます。これが**コムフィルター**です。

遅延を `τ` 秒とすると、単純な同レベル加算で打ち消しが起きる周波数は次です。

```
fcancel = (2n + 1) / (2τ)   n = 0, 1, 2, ...
```

山が生じる周波数は `n/τ` 付近です。ただし実際は2信号のレベル差、反射、マイク特性、音源の動きにより谷の深さが変わります。

### 例題 4-A：0.5 ms遅れ

`τ = 0.0005 s` のとき、最初の谷は：

```
f = 1 / (2 × 0.0005) = 1,000 Hz
```

続く谷は3 kHz、5 kHzです。このような2信号をmixすると、単独では自然でも合成時に細い、空洞のよう、位置で音色が変わる、と感じる場合があります。

### 4.4 録音現場での確認

1. 各マイクを単独で聴き、故障や歪みを先に除外する。
2. 2本を同じ体感音量で加え、低域とアタックの変化を聴く。
3. stereoだけでなくmonoでも確認する。
4. Cubaseで波形を拡大し、到達時刻と極性を観察する。
5. 極性ボタン、位置変更、時間調整を比較し、音量をそろえて選ぶ。

「波形を完全に一直線にすること」が常に芸術的な正解ではありません。複数マイク間の時間差が奥行きや広がりを作ることもあります。目的は見た目ではなく、意図した音色とmono互換性です。

### 理解確認 4

1. 2 kHzに対する0.25 msの時間差は何度ですか。
2. 極性反転と時間遅延の最も重要な違いは何ですか。
3. 1 msの遅延で生じる最初のコムフィルターの谷は何Hzですか。
4. 2本のマイクを合わせた時だけ低域が減る場合、最初に疑う現象は何ですか。

<details>
<summary>答え</summary>

1. `360 × 2,000 × 0.00025 = 180°`。
2. 極性反転は全成分の正負を一律に反転しますが、時間遅延による位相差は周波数に比例して変わります。
3. `1/(2 × 0.001) = 500 Hz`。
4. 到達時間差や極性による干渉。接続・マイク位置・波形・mono合成を確認します。

</details>

## 5. 反射、吸音、拡散、遮音

### 5.1 境界に当たった音

音が壁などの境界へ当たると、エネルギーはおおまかに次へ分かれます。

```
入射エネルギー
  ├─ 反射：室内側へ戻る
  ├─ 吸収：主に熱へ変わる
  └─ 透過：境界の反対側へ進む
```

実際の割合は周波数、入射角、材料、厚さ、施工、背後空気層などで変わります。

- **反射**：音が境界で戻ること。硬く大きな平面は、波長に対して十分大きい周波数を強く反射しやすい。
- **吸音**：室内の音響エネルギーを減らすこと。
- **拡散**：反射エネルギーを多方向・時間方向へ散らすこと。
- **遮音**：部屋の内外を通り抜ける音を減らすこと。

波長に対して十分大きく平らな面では、鏡のような**鏡面反射**として近似でき、面の法線を基準にした入射角と反射角は等しくなります。凹凸が波長に対して無視できない場合は反射が散らばります。低域は波長が長いため、小さな物体の背後へ回り込む回折も起こりやすくなります。

薄い吸音フォームを壁へ貼ると中高域の反射は減らせても、壁を透過する低音が同じだけ減るとは限りません。**吸音と遮音は別の課題**です。

### 5.2 吸音率

吸音率 `α` は、入射した音響エネルギーのうち吸収された割合を表す考え方で、理想化すれば0から1の範囲です。

- `α = 0`：吸収しない理想反射面
- `α = 1`：入射エネルギーをすべて吸収する理想面

実測値は測定方法、周波数、取付条件などに依存し、単一の数値で材料の全帯域性能を表せません。製品を比較するときは周波数帯別の値と試験条件を見ます。

多孔質吸音材は、空気粒子の運動を内部摩擦で減衰させます。厚くする、壁から離して空気層を設けるなどで効く帯域を下へ広げられますが、極低域には大きな厚さが必要です。膜・板・共鳴器を使う吸音は、特定の低域を狙える一方、設計と施工精度が必要です。

### 5.3 初期反射とフラッターエコー

直接音のすぐ後に届く反射を**初期反射**と呼びます。到来方向と遅れによって、定位、明瞭度、音色へ影響します。平行で硬い面の間を往復する目立った反射は、手を叩いた時の「ビーン」「パタパタ」という**フラッターエコー**として聴こえることがあります。

反射をすべて消せば必ず良い部屋になるわけではありません。録音ブース、control room、live roomでは目的が違います。吸音、反射、拡散、部屋寸法、スピーカーと耳の位置を合わせて設計します。

## 6. 定在波、室内モード、残響

### 6.1 定在波

進行波と反対方向へ進む反射波が重なると、位置によって振幅が小さい**節**と大きい**腹**がほぼ固定された定在波ができます。小部屋の低域では、境界間の距離と波長の関係により特定周波数が強く残ります。これを室内モードとして扱います。

直方体室のモード周波数は、理想化すると次です。

```
f(nx, ny, nz) = (c / 2) ×
  sqrt((nx/Lx)^2 + (ny/Ly)^2 + (nz/Lz)^2)
```

`Lx, Ly, Lz` は部屋の各寸法、`nx, ny, nz` は0以上の整数で、3つすべてが0の組合せは除きます。

1方向の境界だけが関係するものを軸モード、2方向なら接線モード、3方向なら斜めモードと呼びます。一般に軸モードは影響が目立ちやすくなります。

理想的な剛壁では、壁面に音圧の腹、空気粒子速度の節ができます。同じ量について隣り合う節と腹の間隔は `λ/4`、節どうしまたは腹どうしの間隔は `λ/2` です。音圧の節と粒子速度の節は同じ場所ではない点に注意します。

### 例題 6-A：長さ4 mの最低軸モード

長さ方向だけを考え、`nx = 1` とします。

```
f = c / (2L)
  = 343 / (2 × 4)
  ≈ 42.9 Hz
```

次の長さ方向モードは約85.8 Hz、その次は約128.6 Hzです。部屋のある位置で42.9 Hzが大きく、別の位置で小さくなる可能性があります。EQだけで1点の谷を大きく持ち上げても、別位置を悪化させたり、スピーカーのheadroomを失ったりします。

### 6.2 残響とRT60

多数の反射が時間的・空間的に密になり、音源停止後も徐々に減衰する現象が残響です。**RT60** は、音源停止後の音圧レベルが60 dB減衰するのに相当する時間です。実測では背景騒音のため60 dB全体を直接測れない場合があり、一定区間の減衰から外挿するT20、T30などが使われます。

残響時間は周波数帯ごとに異なります。「この部屋は0.5秒」と単一値だけで終えず、少なくとも低域・中域・高域の減衰傾向を確認します。

拡散音場を仮定するSabineの概算式は次です。

```
RT60 ≈ 0.161 V / A
A = Σ(αi Si)
```

- `V`：室容積 m³
- `A`：等価吸音面積 m²（sabins）
- `Si`：各面の面積 m²
- `αi`：各面の吸音率

### 例題 6-B：吸音を増やす

容積50 m³、等価吸音面積10 m²の部屋：

```
RT60 ≈ 0.161 × 50 / 10
     ≈ 0.805 s
```

等価吸音面積を15 m²へ増やした概算：

```
RT60 ≈ 0.161 × 50 / 15
     ≈ 0.537 s
```

ただしSabine式は、吸音が空間にある程度分散し、音場が拡散しているという近似です。小さなcontrol roomの低域、吸音が極端に偏った部屋、強い離散反射では、単一のRT値だけで音場を判断できません。周波数帯別の測定と、複数位置での確認が必要です。

### 6.3 実用的な観察順

1. スピーカーと耳を壁・床・天井から同じ距離へ不用意に置かない。
2. 左右対称性を保ちつつ、前後位置を少しずつ変える。
3. 1点だけでなく複数位置を測る・聴く。
4. 低域は配置と十分な厚さの処理を先に検討する。
5. EQは最後の補助とし、深いnullを大boostで埋めようとしない。

### 理解確認 6

3. RT60が短いことは、あらゆる録音で無条件に良いことですか。
4. 容積が同じまま等価吸音面積が2倍になると、Sabine式上のRT60はどうなりますか。

<summary>答え</summary>

## 7. 聴覚器官

### 7.1 空気振動が神経信号になるまで

```
音波
 ↓
耳介 → 外耳道 → 鼓膜
                 ↓
       耳小骨（つち骨・きぬた骨・あぶみ骨）
                 ↓
              蝸牛の液体
                 ↓
        基底膜・有毛細胞
                 ↓
              聴神経 → 脳
```

| 部位 | 主な構造 | 主な役割 |
| --- | --- | --- |
| 外耳 | 耳介、外耳道 | 音を集め、方向に応じたスペクトル変化も与える |
| 中耳 | 鼓膜、耳小骨、耳管 | 空気振動を内耳へ伝え、空気と蝸牛液の間の伝達を助ける |
| 内耳 | 蝸牛、基底膜、有毛細胞 | 周波数ごとに異なる応答を作り、機械振動を神経信号へ変換する |
| 中枢 | 聴神経、脳幹、聴覚野など | 両耳情報や時間・周波数情報を統合し、音として知覚する |

### 7.2 蝸牛の周波数分析

蝸牛内の基底膜では、場所によって機械的性質が異なります。入口に近い基底部は主に高い周波数、奥の頂部は主に低い周波数へ強く応答します。この周波数と場所の対応を**tonotopy（周波数局在）**と呼びます。

基底膜上の有毛細胞が動くと、機械的な変位が電気的な信号へ変換されます。聴覚は単なるマイクではなく、内耳段階から非線形で、周波数選択性と時間特性を持つ系です。

有毛細胞を含む感覚器は基底膜上の**コルチ器**にあります。耳管は中耳と鼻咽腔側を結び、鼓膜の両側の圧力を調整する働きに関わります。

### 7.3 可聴域と聴力

若く健康な人の可聴周波数域は、目安として20 Hz〜20 kHzと説明されることが多いですが、境界は固定ではありません。音圧、年齢、個人差、測定条件、聴取時間で変わり、高域感度は一般に加齢や騒音曝露の影響を受けます。

- **気導**：空気振動が外耳・中耳を通って内耳へ届く経路。
- **骨導**：頭蓋骨の振動が内耳へ届く経路。
- **伝音性難聴**：主に外耳・中耳での伝達に問題がある。
- **感音性難聴**：主に内耳や聴神経系に問題がある。

これらは診断用語です。聴こえの異常、片耳の急な変化、耳鳴り、痛みがある場合は自己判断やEQ補正で済ませず、医療機関へ相談します。

### 7.4 録音時の聴覚保護

聴覚障害の危険は、レベルだけでなく曝露時間にも関係します。ヘッドホンの音量を上げ続けると耳が慣れたように感じることがありますが、安全になったわけではありません。

- 必要以上の大音量を避ける。
- 長時間作業では静かな休憩を入れる。
- 演奏前にcue levelを下げ、会話してから上げる。
- feedbackやclickの突発音を防ぐため、routing確認後に出力を上げる。
- ライブや大音量リハーサルでは適切な聴覚保護具を使う。

## 8. 等ラウドネス、マスキング、臨界帯域

### 8.1 音圧レベルとラウドネスは同じではない

**ラウドネス**は、人が感じる音の大きさです。同じdB SPLの純音でも、周波数が違えば同じ大きさには感じないことがあります。これを整理したものが**等ラウドネスレベル曲線**です。

曲線は「同じ大きさに感じる純音の周波数と音圧レベルの組合せ」を表します。一般に低い再生レベルでは、低域や非常に高い域が中域より小さく感じられやすくなります。レベルが上がると曲線の形も変わります。

**phon（フォン）**はラウドネスレベルの単位です。ある音と同じ大きさに感じる1 kHz純音のdB SPL値で表します。例えば、指定条件で1 kHz・60 dB SPLの純音と同じ大きさなら60 phonです。

**sone（ソーン）**は知覚的な大きさの比を表す尺度です。概略では40 phonを1 soneとし、40 phon以上ではラウドネスレベルが10 phon増すごとにsone値が約2倍になる関係が目安として使われます。これは広い条件で完全に一定の法則ではありません。

> [!TIP]
> 小音量だけでmixすると低域と高域を足しすぎ、大音量だけでmixすると聴覚疲労と安全上の問題が起きやすくなります。基準にする中程度の音量を保ち、ときどき小音量でバランスを確認します。

### 8.2 マスキング

**マスキング**は、ある音の存在によって別の音が聴こえにくくなり、聴覚上の閾値が上がる現象です。

- **同時マスキング**：maskerと対象音が同時に存在する。
- **時間マスキング**：maskerの前後にある短い音の聴こえ方が影響される。
  - forward masking：強い音の後の音が聴こえにくい。
  - backward masking：強い音の直前の音が影響される。一般に時間範囲は短い。

同時マスキングは、周波数が近いほど強くなりやすいものの、レベルや音の種類にも依存します。一般に低い周波数の強い音が、より高い周波数側を広く隠しやすい**上方への広がり**が見られますが、単純な固定幅ではありません。

ミックスで「ボーカルを聴かせるためにフェーダーを上げる」以外にも、競合する楽器の帯域・発音タイミング・定位・アレンジを変える方法があります。

### 8.3 聴覚フィルターと臨界帯域

内耳は、連続した多数の**聴覚フィルター**のように周波数を分析すると考えられます。ある中心周波数の信号を隠すnoiseについて、一定範囲まではnoise帯域を広げるほどmaskingが増えますが、さらに遠い周波数を加えても影響が増えにくくなります。この考えから得られる有効な周波数幅を**臨界帯域**と呼びます。

重要な点：

- 臨界帯域の幅は全帯域で一定のHz幅ではない。
- 高域になるほどHzで見た幅はおおむね広くなる。
- Bark尺度は可聴域をおよそ24の臨界帯域に対応づける知覚尺度。
- ERB（equivalent rectangular bandwidth）は聴覚フィルター幅を表す別の代表的尺度。
- 1/3オクターブ帯域と臨界帯域は関連する部分があっても、同義ではない。

### 例題 8-A：EQより先に考えること

ギターとボーカルが同じ時刻・近い帯域・中央定位で鳴り、歌詞が聴こえにくいとします。

1. ボーカルを上げる前に、ギターを1〜2 dB下げて比較する。
2. ギターの競合帯域を狭く決めつけず、歌声と交互にsoloして探す。
3. ギターの発音、voicing、左右配置、空間処理も検討する。
4. bypass時と処理後の体感音量をそろえ、改善したか確認する。

マスキングは「同じ周波数が1つあるから発生する」のではなく、帯域、時間、レベル、定位の相互作用です。

## 9. 両耳聴と音像定位

### 9.1 左右方向の主な手掛かり

左右の耳へ届く音は、方向によって時刻とレベルが少し違います。

- **両耳間時間差（ITD）**：左右の耳へ到達する時間の差。低域から中域の左右定位で重要。
- **両耳間レベル差（ILD / IID）**：頭部の遮蔽による左右のレベル差。波長が頭部寸法より短くなる高域で大きくなりやすい。
- **両耳間位相差（IPD）**：周期信号の左右の位相差。高い周波数では同じ位相差に複数の到来方向が対応しやすく、曖昧になる。

```
左からの音
音源 → 左耳（早い・大きい） → 頭部 → 右耳（遅い・高域が小さめ）
```

頭を球とみなす単純なモデルでは、左右耳間の最大到達差はおよそ0.6〜0.7 ms程度になりますが、頭の大きさ、方向、定義、モデルで変わります。この数値だけで定位を計算し切れるわけではありません。

### 9.2 上下・前後と耳介

正面・背面・上下の音は、ITDとILDだけでは似た値になる組合せがあります。耳介、頭部、胴体が方向ごとに作る細かなスペクトル変化が、前後・上下の判断を助けます。これらをまとめた伝達特性をHRTF（頭部伝達関数）と呼びます。

頭を動かした時に手掛かりがどう変わるか、視覚情報、部屋の反射も定位へ影響します。ヘッドホンで同じHRTFを全員に使っても、耳介形状の個人差により前後誤りや頭内定位が起こることがあります。

### 9.3 先行音効果

同じ音が短い時間差で複数方向から届くと、条件によっては別々の音としてではなく1つに融合し、先に届いた音の方向へ定位しやすくなります。これを**先行音効果**と呼びます。遅れが長く、レベルが大きく、音の性質が変わるとechoとして分離します。境界となる時間を単一の固定値で覚えず、音の種類、レベル差、方向、部屋で変わると理解します。

### 9.4 stereoのphantom image

左右スピーカーから同じ信号を同じ時刻・同じレベルで再生すると、正しい配置と聴取位置では中央に**phantom center**を感じます。左右レベル差を付けるlevel差stereo、時間差を付ける時間差stereoがあり、実際の録音方式は両方の手掛かりを含むことがあります。

| 方式 | 主な手掛かり | 特徴と注意 |
| --- | --- | --- |
| XY | 主にレベル差 | capsuleを近接、時間差が小さくmono互換性を得やすい |
| AB | 主に時間差＋一部レベル差 | 広がりを得やすいが、mono時の干渉を確認する |
| MS | MidとSideをmatrix変換 | 後から幅を調整でき、正しく変換すればmonoはMid中心 |
| ORTFなどnear-coincident | 時間差＋レベル差 | 人頭寸法を模した間隔・角度で自然な広がりを狙う |

方式名だけで優劣は決まりません。音源幅、距離、部屋、狙う像、mono互換性で選びます。

### 例題 9-A：中央からずれた理由

同じmono信号を左右へ送ったのに中央から少し右へ聴こえる場合：

1. 左右channelのlevelとpanを確認する。
2. スピーカーから耳までの距離を測る。
3. 左右スピーカーのgain、極性、配線を確認する。
4. 左右壁面の反射条件と部屋の対称性を確認する。
5. 別の信頼できるmono音源、headphone、左右入替えで切り分ける。

「自分の耳」「mix」「機器」「配置」「部屋」を順番に分けて考えます。

2. 波長が短くなると頭部による遮蔽が強まり、反対側の耳へ届く高域が減りやすいからです。
3. 耳介・頭部・胴体による方向別のスペクトル変化、つまりHRTFの手掛かり。
4. XYはcapsuleを近接させ時間差を小さくし、ABはマイク間隔による時間差を積極的に使います。
5. いいえ。左右スピーカーの信号から聴覚が中央に構成する虚像です。

</details>

## 10. 倍音、部分音、音色

### 10.1 周期音の成分

- **基音（fundamental）**：周期 `T` を持つ音の基本周波数 `f0 = 1/T`。
- **倍音（harmonic）**：基音周波数の整数倍の成分。第 `n` 倍音は `n f0`。
- **部分音（partial）**：複雑な音を構成する個々の周波数成分。整数倍でない成分も含む。
- **上音（overtone）**：基音より上の成分を数える呼び方。第1上音は通常、第2倍音に当たる。

100 Hzを基音とする理想的な調波複合音なら、100、200、300、400 Hz…が倍音です。230 Hzの成分が含まれても、それは部分音ですが100 Hzの整数倍ではないため倍音ではありません。

基音が物理的に弱い、または存在しなくても、整数倍の上位成分から基音に相当するpitchを感じることがあります。これを**missing fundamental（欠落基音）**の知覚と呼びます。

### 10.2 倍音だけでは音色を説明し切れない

音色には次が関係します。

- 倍音・非整数次部分音・noiseの相対level
- attack、decay、sustain、releaseなどの時間包絡
- 音高や音量に伴うスペクトル変化
- vibrato、tremolo、揺らぎ
- 発音直後のtransient
- 演奏空間とマイク位置

同じ平均スペクトルでも、立ち上がりを切ると楽器の識別が難しくなることがあります。周波数だけでなく時間変化を見ます。

### 10.3 弦と気柱の理想モデル

両端固定の理想弦の固有周波数：

```
fn = n/(2L) × sqrt(F/μ)
```

- `L`：弦長
- `F`：張力
- `μ`：線密度（単位長さあたり質量）
- `n = 1, 2, 3, ...`

弦を短くする、張力を上げる、線密度を小さくするとpitchは上がります。

両端開放の理想的な管：

```
fn = n c/(2L)   n = 1, 2, 3, ...
```

一端閉鎖の理想的な管：

```
fn = (2n - 1)c/(4L)   n = 1, 2, 3, ...
```

一端閉鎖管は理想化すると奇数次成分が固有モードとして現れます。実際の楽器は開口端補正、形状、材質、吹奏・擦弦・打弦方法、非線形性などにより理想式からずれます。

### 理解確認 10

1. 200 Hzが基音なら、第3倍音は何Hzですか。
2. 第1上音は通常、第何倍音ですか。
3. 部分音と倍音の違いは何ですか。
4. 同じ倍音構成の静止スペクトルでも音色が違い得る理由を1つ挙げてください。
5. 同じ弦で張力を4倍にすると、理想式上の基音周波数は何倍ですか。

<details>
<summary>答え</summary>

1. 600 Hz。
2. 第2倍音。
3. 部分音は音を構成する各周波数成分の総称、倍音は基音の整数倍にある部分音です。
4. 例：立ち上がり、減衰、揺らぎ、noise、transientが異なるため。
5. `sqrt(4) = 2` なので2倍。

</details>

## 11. 音律、音程、うなり

### 11.1 音程は周波数比

音程は2音のpitch間隔です。物理的には周波数の**差**より**比**が重要です。

| 音程 | 純正な整数比の代表例 |
| --- | ---: |
| オクターブ | 2:1 |
| 完全5度 | 3:2 |
| 完全4度 | 4:3 |
| 長3度 | 5:4 |

整数比が単純な2音では倍音の一部が一致します。ただし音楽的な協和・不協和は、音色、文化、文脈、調律法にも依存します。

### 11.2 代表的な音律

- **純正律**：特定の調や和音で単純な整数比を重視する。転調すると同じ音名でも理想周波数が合わなくなる。
- **ピタゴラス音律**：主に純正な3:2の完全5度を積み重ねる。3度などに大きなずれが出る。
- **中全音律**：3度の響きを改善するため5度を調整する諸方式。
- **12平均律**：1オクターブを周波数比で等しい12区間へ分ける。全調を同じ鍵盤配置で扱いやすい代わりに、オクターブ以外の多くの音程は純正比から少しずれる。

12平均律で半音上がる周波数比は：

```
r = 2^(1/12) ≈ 1.059463
```

基準音から `n` 半音離れた周波数：

```
f(n) = fref × 2^(n/12)
```

### 例題 11-A：A4から7半音上

A4を440 Hzとし、7半音上のE5を求めます。

```
f = 440 × 2^(7/12)
  ≈ 659.26 Hz
```

純正な完全5度なら `440 × 3/2 = 660 Hz` です。12平均律の完全5度は純正比よりわずかに狭くなります。

### 11.3 cent

1オクターブを1,200等分した比率尺度がcentです。12平均律の半音は100 centです。

```
cents = 1200 log2(f2 / f1)
```

### 例題 11-B：440 Hzと442 Hz

```
cents = 1200 log2(442/440)
      ≈ 7.85 cent
```

Hz差が同じ2 Hzでも、基準周波数が変わればcent差は変わります。

### 11.4 うなり

近い2周波数の正弦波を重ねると、振幅が周期的に増減して聴こえます。単純な条件でのうなり周波数は：

```
fbeat = |f2 - f1|
```

440 Hzと443 Hzなら、1秒に約3回のうなりです。調律ではうなりを手掛かりにできますが、実楽器では複数の部分音がうなり、inharmonicityもあるため、基音差だけでは説明し切れません。

### 11.5 基準pitch

A4 = 440 Hzは広く使われる基準ですが、すべての演奏が必ず440 Hzとは限りません。orchestra、古楽、地域、作品、制作方針により別の基準が使われます。録音session前に基準pitchを全員で共有します。

### 理解確認 11

1. 440 Hzの1オクターブ上と下は何Hzですか。
2. 12平均律で3半音上の周波数を求める式を書いてください。
3. 450 Hzと454 Hzの単純なうなり周波数は何Hzですか。
4. 12平均律の長所と妥協点を1つずつ説明してください。
5. Hz差とcent差は同じ意味ですか。

<details>
<summary>答え</summary>

1. 上は880 Hz、下は220 Hz。
2. `f = 440 × 2^(3/12)` のように書きます。
3. `|454 - 450| = 4 Hz`。
4. 長所：全調をほぼ同じ条件で扱いやすい。妥協点：オクターブ以外の多くの音程が純正な整数比から少しずれる。
5. 違います。Hzは周波数の差、centは周波数比を対数で表した音程尺度です。

</details>

## 12. 横断例題

### 例題 12-A：部屋の寸法、波長、モードを結ぶ

長さ3.43 mの部屋で、長さ方向の最低軸モードを求めます。

```
f = c/(2L)
  = 343/(2 × 3.43)
  = 50 Hz
```

50 Hzの波長は：

```
λ = 343/50 = 6.86 m
```

最低軸モードでは、部屋長3.43 mが半波長に相当します。したがって「部屋の長さと同じ波長」ではなく、「両端が境界となる最低軸モードでは部屋長が半波長」と説明します。

### 例題 12-B：マイク距離差から干渉を見積もる

同じ音源に対する2本のマイクの経路差が17.15 cmとします。時間差は：

```
τ = 0.1715/343 = 0.0005 s = 0.5 ms
```

最初の打ち消し周波数：

```
f = 1/(2τ) = 1,000 Hz
```

ただし、マイクのレベル・指向性・反射が違えば完全なnullにはなりません。計算は「どこを疑うか」の手掛かりです。

### 例題 12-C：音圧比と距離を区別する

自由音場の点音源から1 mで90 dB SPLだったとします。2 mでは理想的に約84 dB SPLです。これは音圧が約1/2になったため `20 log10(1/2) ≈ -6 dB` です。

ここで「音響強度は1/4」です。音圧比に20、強度比に10を使うと、どちらも同じ `-6 dB` になります。

```
20 log10(1/2) = -6.02 dB
10 log10(1/4) = -6.02 dB
```

### 例題 12-D：低音を大きくしすぎた理由

深夜、小音量でbassが足りないと感じ、60 Hzを大きくboostしました。翌日、中程度のlevelでは低音過多でした。

考えられる要因：

1. 小音量では等ラウドネス特性により低域を相対的に小さく感じた。
2. 監視位置が60 Hz付近の定在波の節に近かった。
3. referenceとのlevel matchingをしていなかった。
4. 長時間作業による判断変化があった。

対策は、EQを戻して基準level・複数音量・複数位置・referenceで再確認することです。1つの測定値や1回の聴感だけで原因を決めません。

## 13. 試験で混同しやすい組合せ

| 混同 | 正しい区別 |
| --- | --- |
| 周波数と音速 | 周波数は振動回数、音速は媒質中の伝搬速度 |
| amplitudeとloudness | amplitudeは物理量、loudnessは知覚量 |
| `0 dB SPL` と無音 | `0 dB SPL` は20 µPaという基準レベル |
| `0 dBFS` と `0 dBu` | full scale基準と0.775 Vrms基準で別物 |
| 音圧2倍と電力2倍 | 音圧2倍は約+6 dB、電力2倍は約+3 dB |
| 位相と極性 | 時間差の位相は周波数依存、極性反転は正負を一律反転 |
| 吸音と遮音 | 室内エネルギーを減らすことと、境界透過を減らすこと |
| 定在波と残響 | 固定した節・腹を作る現象と、反射群が時間減衰する現象 |
| SPLとphon | 物理的な音圧レベルと主観的なラウドネスレベル |
| 倍音と部分音 | 倍音は基音の整数倍、部分音は非整数成分も含む |
| 第1上音と第1倍音 | 通常、第1上音は第2倍音。第1倍音は基音 |
| Hz差とcent差 | 周波数の引き算と、周波数比の対数尺度 |
| phantom centerと実音源 | 左右信号から知覚される虚像と、中央の実スピーカー |
