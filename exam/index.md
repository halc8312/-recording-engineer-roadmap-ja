# JAPRS独学コース

このコースは、JAPRSが公開している出題範囲と公開過去問題の傾向を手掛かりに、必要な基礎知識を**独自の文章・図表・計算例・練習問題**で学ぶための無料教材です。JAPRS公式教材の転載・要約版・公式講座ではありません。

::: warning 最初に知っておくこと
この試験は合格・不合格を決める試験ではありません。1000点満点の得点によりA〜Eランクと分野別成績が交付されます。このコースでは、まずBランク帯を目指せる基礎を作り、その後Aランク帯に必要な規格・歴史・用語の精度を上げます。特定ランクは保証できません。
:::

## 試験の形

| 項目 | 内容 |
| --- | --- |
| 形式 | 四者択一・マークシート |
| 時間 | 90分 |
| 問題数 | 4分野×25問＝100問 |
| 評価 | A：901〜1000、B：701〜900、C：451〜700、D：201〜450、E：200以下 |
| 公式出題元 | 技術概論、問題集・技術資料集、音響設計ガイドブック |

年度により内容・日程・価格が変わるため、受験前に[JAPRS公式の実施要項](https://www.japrs.or.jp/exam/soundrecording/guide/)と[出題範囲](https://www.japrs.or.jp/exam/soundrecording/range/)を確認してください。

## 「公式教材5,600円分」に対して作ったもの

[2026年度の公式教材案内](https://www.japrs.or.jp/exam/soundrecording/text/)では、Kindle版技術概論2,500円、問題集・技術資料集2,000円、音響設計ガイド1,100円（後二者は送料別）です。このサイトは内容を複製せず、公開出題範囲に必要な学習機能を次のように独自制作しています。

| 公式教材が担う役割 | この無料コースで担うもの |
| --- | --- |
| 技術概論の10章 | 7章の本文、計算例、理解確認、章末チェック |
| 問題集 | 4分野×40問＝160問の独自問題庫、25問練習、100問模試 |
| 技術資料集 | [直前クイックリファレンス](quick-reference.md)と[日英用語集](glossary.md) |
| 音響設計ガイド | [07 スタジオ音響設計](07-studio-acoustics-design.md) |
| 学習管理 | [16週間プラン](study-plan.md)、端末内の進捗保存、JSONバックアップ |

これは公式3冊の複製や、同一内容・同一品質の保証ではありません。非公開の出題意図や次年度固有の話題は事前に再現できないため、最終判定にはJAPRSが無料公開している公式過去問題も使います。有料教材を買わずに、本文・演習・模試・復習・公開過去問題まで進められる設計です。

### 0円で進める受験ルート

`10問診断 → 7章を一周 → 分野別25問 → 直前確認 → 独自100問 → 公式公開過去問題`

この順なら教材購入なしで、知識の入力、計算、反復、時間制限演習、弱点分析まで行えます。点数が伸びない項目だけ、後から公式教材を買うか判断できます。

## 学び方

1. 最初に[独自模試・問題練習](mock-exam.md)の10問診断を受ける。
2. 章を読み、例題を紙に書いて解く。
3. 資料を閉じ、重要語を自分の言葉で説明する。
4. 分野別25問で80%に届かなければ、誤答から該当節へ戻る。
5. 48時間後と1週間後に、答えを見ずに再確認する。
6. 最後に100問・90分を受け、分野ごとの弱点を記録する。

「読んだ」と「解ける」は別です。正解しても根拠を説明できなければ未習得として扱います。

## 目標の段階

### Stage 1：基礎を一周

- 各章の理解確認で80%以上
- dB、周期・周波数、波長、Ohmの法則、tempo計算を式から解ける
- 信号経路を紙に描ける
- 権利・歴史・楽器を混同せず分類できる

### Stage 2：Bランク帯を目指す準備

- 未見の分野別問題で各70%以上
- 本番形式100問を90分以内に完了
- 4分野すべてで70%以上、総合75%以上を3回中2回
- 誤答の根拠を教材または一次資料で確認済み

### Stage 3：Aランク帯へ精度を上げる

- 未見の本番形式で92%以上を複数回
- 規格値、楽器音域、著作権、録音史を遅延復習で維持
- 計算問題を途中式付きで短時間に処理
- 公開過去問題でも分野別の弱点が残っていない

これらはこの教材内の学習目安であり、JAPRSによる合格基準や認定保証ではありません。

## 公式公開問題の使い方

JAPRSは過去の試験問題と解答を公開しています。著作権を尊重し、このサイトへ問題文を転載しません。[公式の過去問題ページ](https://www.japrs.or.jp/exam/soundrecording/past/)を開き、次の順で使ってください。

1. 初回は90分、資料なしで解く。
2. 4分野それぞれの正答数を記録する。
3. 誤答を「未学習」「暗記不足」「計算」「読み違い」に分類する。
4. 公式解答だけで理由が分からない問題は、該当教材と一次資料へ戻る。
5. 同じ問題を覚えるのではなく、数値や状況を変えた問題を自分で作る。

::: tip 実務コースと並行するなら
録音やmixの実技は[12週間ロードマップ](/ROADMAP)で進め、試験知識はこのコースで別に記録します。両方を同じ週に詰め込まず、試験コースは1日30〜45分に分割すると続けやすくなります。
:::
